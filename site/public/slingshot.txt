- Product type: Desktop application
- Category: Developer tools / Dev environment launcher
- Tagline: Open your full dev environment with one click

## Platforms (supported operating systems)

- macOS: yes (DMG installer, .dmg)
- Windows: yes (NSIS .exe installer, MSI installer)
- Linux: yes (Debian .deb, Fedora/RHEL .rpm, AppImage portable)
- Architecture: x86_64 and Apple Silicon (per platform Tauri defaults)

## Requirements

- Disk space: ~100 MB for the binary
- Internet: not required for normal use after installation
- Optional for development from source:
  - Node.js 22 or newer
  - pnpm 10 or newer
  - Tauri 2 system dependencies (per OS, see https://v2.tauri.app/start/prerequisites/)
  - Stable Rust toolchain with `rustfmt` and `clippy`

## Capabilities (feature list)

- Launch a code editor, multiple terminals, browser tabs, and dev servers from one click
- Embedded terminal using real PTY (portable-pty in Rust) and xterm.js in the frontend
- Project library with tags, favorites, search, and notes
- Ordered command sequences (run multiple shell commands in sequence on launch, e.g. `git pull` → `npm install` → `npm run dev`)
- Pre-launch checks (verify Node, Git, Docker, and port availability before launch)
- Git status visible on every project card (branch, uncommitted changes, ahead/behind)
- Local SQLite storage via `tauri-plugin-sql`
- Native folder picker via `tauri-plugin-dialog` (no manual path entry)
- Window state persistence via `tauri-plugin-window-state`
- Auto-update via `tauri-plugin-updater`
- Structured logging via `tauri-plugin-log`
- Process execution via `tauri-plugin-shell` (argument arrays, never string-concatenated shell)

## Tech stack

- App shell: Tauri 2 (Rust backend, OS-native webview)
- Frontend framework: Vue 3
- Language: JavaScript (no TypeScript in the main app)
- CSS framework: Tailwind CSS 4.3
- Local storage: SQLite (via `tauri-plugin-sql`)
- Embedded terminal: `portable-pty` (Rust) + `xterm.js` (frontend)
- State management: Pinia (Vue)
- Build tool: Vite
- Package manager: pnpm
- Bundler / desktop packager: `tauri build` + `tauri-action` (GitHub Actions)

## Comparison with adjacent products

- Vs. shell scripts / Makefiles: Slingshot provides a GUI library, embedded terminal, per-project launch profiles, pre-launch checks, and discoverability without requiring the user to write or maintain a script.
- Vs. project manager SaaS (Linear, Jira, Asana): Slingshot is local-first, single-user, and focused on launching dev environments — not on issue tracking or collaboration.
- Vs. devcontainers / GitHub Codespaces: Slingshot launches the user's local machine's tools, not a remote container. No cloud cost, no cloud account, full speed.
- Vs. tmuxinator / Foreman: Slingshot is GUI-first and editor-agnostic, with a project library and tag-based organization.
